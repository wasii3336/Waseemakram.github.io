    How the flow works — your on-site routine, done from the desk
    
    
    At Pace, the visit was for diagnosis, not the fix. This flow does that diagnosis remotely, in the same order, so only a physically broken cable still needs a visit.
    
    
    
      
    1 Online status
    Is the customer online? If offline, is the account in good standing or is it billing?
    
      
    2 Speed usage
    Read live usage on MikroTik. Using the full allocated speed explains “slow” — no fault.
    
      
    3 Fibre signal
    ONT signal in dBm. Around −20 is normal; near −30 or worse points to a physical fault.
    
      
    4 Restart via OLT
    Restart the ONT remotely. A stuck router is the most common fix — no visit needed.
    
      
    5 Re-check signal
    Read the signal again after restart. If it degraded, the fault is physical.
    
      
    6 Redial from server
    Redial the PPPoE session from the server. Last remote step before a visit is booked.
